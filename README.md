# Nitish Kumar — Developer Portfolio

A lightweight, responsive portfolio built with semantic HTML, CSS and vanilla JavaScript. No build step or package installation is required.

## Run locally

Open `index.html` in a browser, or serve this directory with any static file server.

## Portfolio sections

- Intro and profile links
- About and technical skills
- Professional experience and education
- Selected projects with live/source links and category filters
- Achievements and certificates
- Contact details and a Formspree contact form

## Updating content

- Edit `index.html` to update profile, résumé, project, education and contact details.
- Replace `Nitish CV.pdf` to update the résumé download.
- Edit `styles.css` to adjust the theme, layout and responsive styles.
- Edit `script.js` to update navigation, project filtering or contact form behavior.

The portfolio uses the existing `image.jpg` portrait. Technology marks and web fonts load from their public CDNs; the Farm2Door screenshot is hosted in a GitHub attachment. The contact form uses the existing Formspree endpoint.
